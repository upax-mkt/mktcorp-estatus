# El Home empieza por los clientes — Plan

> **Para quien ejecuta con agentes:** SUB-SKILL OBLIGATORIA:
> `superpowers:subagent-driven-development`. Los pasos usan casillas (`- [ ]`).

**Goal:** Que lo primero que se vea al entrar sean **las salas**, y debajo los
módulos generales; que los acuerdos dejen de ocupar media portada y queden
como **una cifra que lleva a su pestaña**.

**Architecture:** Reordenar y quitar. No hay dato nuevo, ni Server Action
nueva, ni migración. Lo único que se retira es el módulo de acuerdos del Home;
todo lo demás cambia de sitio.

**Tech Stack:** Next 16, React 19, TypeScript, CSS Modules, Vitest + Testing
Library.

**Spec:** `docs/superpowers/specs/2026-08-14-ronda14-clases-home-y-reuniones-design.md` §4.

## Global Constraints

- **Todo en español**, comentarios densos en POR QUÉ y con el número medido.
- **Decisión de Franco, textual:** los acuerdos salen del Home y quedan
  **"solo una cifra"**. No es un módulo más pequeño: es una cifra.
- **Ningún `UPDATE` sobre datos existentes**, ninguna columna retirada.
- La base local **ES la de producción**: solo GET al navegar.
- ⚠️ **Nunca `git add -A` ni `git add .`**; nunca `git stash`, `git checkout`
  de archivos ni `git rebase`.
- Comandos: `npx vitest run <ruta>` · `npx tsc --noEmit` · `npx eslint src/` ·
  `npm run build`.
